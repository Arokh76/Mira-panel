# Mira Panel — canal stable

Ce canal est réservé aux versions du **plugin Jeedom Mira Panel validées** après tests sur `beta`.

**Aucune version stable n'a encore été publiée.** Ne pas sélectionner cette branche comme source de mise à jour Jeedom tant que `plugin_info/info.json` et les autres dossiers du plugin ne sont pas présents.

Cycle de publication :
1. Les nouvelles versions du plugin sont publiées sur `beta` et testées sur Jeedom.
2. Une fois les tests validés, publier **le commit exact** testé de `beta` ici (sur demande explicite).
3. Les utilisateurs du canal `stable` récupèrent ensuite cette mise à jour depuis Jeedom.

Le firmware des écrans continue à être géré indépendamment sur `main` et n'est pas distribué par ce canal.
