# Archive : Mira ESP-IDF Waveshare 4,3C

Ce dossier conserve le projet ESP-IDF historique 4,3 pouces, intact dans ses 54 fichiers d'origine. Il a été déplacé depuis `firmware/experiments/esp-idf/mira-idf/` le 13 novembre 2026 pour clarifier la branche `firmware-beta`.

Il **ne constitue pas** les sources du Waveshare 7 pouces. Le seul développement ESP-IDF actif du 7 pouces se fait depuis [`esp-idf/`](../esp-idf/).

L'ancien workflow de build 4,3C est archivé dans `.github/archive/workflows/build-mira-idf-waveshare.yml` et n'est plus actif. Pour reprendre ce projet 4,3C, il faudra le réactiver volontairement et adapter son chemin ; aucun code de ce projet n'a été réécrit pendant le classement.
