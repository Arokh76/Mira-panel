# Projet Tamagotshi 🐣

Petit projet DIY de Tamagotchi sur **LilyGO T-Display V1.1** (ESP32, écran ST7789 135 × 240, deux boutons).

## Objectif du premier essai

- Afficher une petite créature animée à l’écran.
- Utiliser les deux boutons intégrés pour la nourrir et jouer avec elle.
- Rester entièrement autonome : pas de Wi-Fi, de Jeedom, de MQTT ni de serveur pour ce test.

## État du projet

Dossier initial créé pour regrouper le code source, les essais et les futurs firmwares `.bin` compatibles avec Espressif Flash Download Tools.

**Attention : aucun firmware n’est encore compilé ni validé sur le matériel.**

Le projet est indépendant de Mira Panel malgré son hébergement dans ce dépôt.
