Installer Mira Panel

Branchez votre écran en USB et installez le firmware directement depuis votre navigateur. Aucun logiciel ni Arduino IDE n'est nécessaire.

Version du firmware …
  1. 1
    Branchez l'écran en USBUtilisez le port USB de l'écran relié directement à votre ordinateur.
  2. 2
    Cliquez sur « Installer Mira Panel »Sélectionnez le port série proposé par Chrome ou Edge.
  3. 3
    Laissez l'installation se terminerL'écran redémarre ensuite sur Mira Panel et vous pouvez poursuivre sa configuration.

Première installation / restauration complète

Choisissez votre modèle pour installer uniquement son firmware. La détection USB d'un ESP32-S3 ne permet pas toujours d'identifier la carte exacte.

Sélectionnez le modèle indiqué sur votre carte avant de flasher.
Le bouton d'installation apparaît dès qu'un firmware compatible est disponible.

Attention : l'installation USB complète efface la configuration présente sur l'écran. Pour une mise à jour normale d'un Mira Panel fonctionnel, utilisez uniquement l'OTA depuis son interface.

Après l'installation : configurez le Wi-Fi de l'écran, puis revenez dans le plugin Jeedom Mira Panel pour créer l'équipement et programmer vos widgets.
